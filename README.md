# QueueAdvisor

> AWS queue services pricing advisor — SQS, Kinesis, EventBridge, MSK.

![Status](https://img.shields.io/badge/status-active-success)
![Stack](https://img.shields.io/badge/stack-Next.js-informational)
![License](https://img.shields.io/badge/license-MIT-blue)

## Overview

Interactive tool that compares cost and fit for AWS messaging services (SQS, Kinesis, EventBridge, MSK) based on your throughput and retention requirements. Built for solution architects making messaging decisions.

## Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**

## Features

- Side-by-side comparison
- Usage-based cost simulation
- Decision guidance

## Getting Started

```bash
# Clone the repository
git clone https://github.com/fernandofatech/queue-advisor-pricing-app.git
cd queue-advisor-pricing-app

# Install dependencies
pnpm install

# Run in development
pnpm dev
```
